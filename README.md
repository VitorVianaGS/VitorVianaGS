- **Backend:** JavaScript, Node.js, APIs, integrações, bancos de dados e conceitos de aplicações no servidor.

- **Automação:** scripts, automatização de tarefas repetitivas, otimização de processos e integração de sistemas.
- **Inteligência Artificial:** fundamentos de aprendizado de máquina, conceitos de aprendizado profundo, processamento de linguagem natural e aplicações de IA.
